울림 · 손끝으로 조절

워치는 소리를 느끼고, 휴대폰은 설정만 바꿔요.

워치에 연결하는 중…

마이크 입력 → 모터 보정 후—
변환된 소리 → 진동 요청—

입력과 진동 %는 서로 다른 기준이에요. 실제 모터 힘의 측정값은 아니에요.

소리 → 진동 곡선

민트색 점을 위아래로 움직이세요. 위로 올리면 그 크기의 소리가 더 강하게 느껴져요.

세 점 사이도 연속으로 계산해요. 곡선은 반응 시간·AI 미세 조정 전의 지속음 기준이며, 노란 점은 현재 소리와 실제 요청값이에요.

자주 쓰는 조절

진동의 길이·끊김

위쪽은 켜짐, 아래쪽은 꺼짐이에요. 현재 요청이 일정할 때의 예상 파형이며 실제 피부 진동을 측정한 그래프는 아니에요.

모든 상세 설정 · 35개

기존 항목을 모두 유지했어요. 범위와 앞뒤 순서에 맞게 적용돼요.

저장과 복원

바꾼 값은 워치에 자동 저장돼요. ‘저장됨’을 확인하면 휴대폰을 닫거나 워치를 재시작해도 유지돼요.

조절 중에는 워치의 ‘휴대폰에서 조절’ 화면을 열어 두세요. 감지 시작은 워치에서 직접 해주세요.
