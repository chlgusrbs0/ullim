# 실시간 상세 조절

메인 또는 설정의 **실시간 상세 조절**에서 6개 분류의 35개 값을 조절한다. 메인에서 직접 감지를 시작한 뒤 들어오면 감지를 유지한 채 바꿀 수 있다. `− / +`는 항목별 작은 간격으로 즉시 적용하며 숫자 입력은 **입력값 적용**을 누른다. 화면 위의 숫자가 실제 적용값이다.

모든 변경은 워치 내부 설정 파일에 자동 저장한다. **저장됨** 상태가 되면 앱 종료·워치 재시작 후에도 복원된다. 저장 실패 시 화면에 오류와 재시도가 나온다. 다른 워치나 앱 삭제 후까지 보존하는 기능은 아니다. 이 항목 기본값/상세 조절 전체 기본값으로 복원할 수 있으며 상세 전체 복원은 AI ON/OFF·기존 민감도·모터 보정값을 바꾸지 않는다.

| 분류 | 조절 내용 |
|---|---|
| 입력·무음 판단 (10) | 강한 입력 기준, 작은 소리 확대 곡선, 최소 입력, 배경 여유, 감지 시작/유지 추가값·배율, 배경 상승/하강 학습 속도 |
| 반응·끊김 (5) | 입력 반응/감쇠 시간, 진동 증가/감소 반응, 짧은 무음 이어주기 |
| 진동 강약 곡선 (8) | 전체 배율·강약 대비·시작 강조, 25/50/80% 소리의 대응 진동, 출력 하한/상한 |
| 펄스 길이·전환 (5) | 긴 펄스 전환 시작/완료, 묶음 길이, 최소 ON 시간, 묶을 수 있는 세기 차이 |
| 모터 소음 보정 (2) | 보정 제거 세기, 잔향 유지 시간 |
| AI 미세 조정 (5) | 최소 점수·후보 차이, 변화 반영 속도, 최대 조정 폭, 늦은 문맥 적용 대기 |

25/50/80%는 세 단계 분류가 아닌 **연속 곡선의 제어점**이다. 제어점 사이는 선형 보간한다. 입력 %는 보정된 디지털 소리 크기이며 진동 요청 %와 같은 척도가 아니다. 실제 모터 힘을 측정한 수치도 아니다.

원인별로 확인할 값:

- 평소 대화부터 모두 강함: 작은 소리 확대 곡선을 높이거나, 강한 입력 기준을 높이거나, 50% 지점 대응 진동을 낮춘다. 긴 펄스 전환 시작/완료를 높이면 더 큰 요청부터 긴 펄스가 된다.
- 화면이 무음 판단으로 바뀌며 말소리 중간이 끊김: 감지 유지 추가 기준/배율·최소 입력을 확인한다. 짧은 무음 이어주기는 기본 0ms이며 20~100ms로 직접 선택할 수 있다. 활성화한 경우 실제 소리 종료도 선택한 시간 이내로 늦어지고 감쇠한다. 이어준 진동은 연장 타이머를 다시 시작하지 않는다.
- 화면 요청이 유지되는데 피부에서는 끊김: 최소 펄스·묶음 길이·전환 구간을 확인한다. 이는 실제 무음 판단 문제와 별개다.
- 모터 소음 제거를 낮추면 외부 소리가 더 남지만 워치 자체 진동이 재감지될 수 있다. 새 자기 진동이 이어지면 감지 중지 후 해당 값을 복원한다.

최종 기본값은 사용자가 확정한 PR86의 MvpDefaults를 사용한다. 기존 PR83은 이 화면이 처음 도입됐을 때의 기준이다. DSP 20ms와 출력 배치 60ms는 그대로 두므로 설정 화면의 저장을 기다리느라 소리 처리가 멈추지 않는다. 조절 가능한 펄스 범위에서 보정용 20%/100% 파형을 동일하게 유지하므로 이 변경 자체로 재보정은 필요하지 않다.

AI는 번들 YAMNet으로 별도 추론한다. 신선하고 확실한 동일 문맥에서 작은 진동 흔들림만 제한적으로 완화한다. 첫 반응·큰 강약 변화·무음은 기본 소리 경로를 따르며 소리 종류별 고정 강도나 음원 분리를 수행하지 않는다. `AI 분석 보기`에서 후보와 실제 적용 상태를 확인할 수 있다. 설정 화면 열기·값 변경은 마이크를 시작하지 않는다.
