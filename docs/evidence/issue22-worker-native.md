## 실제 워치 실행

SM-L300 / Android17 API37 / L300XXU2ZZK1,2026-11-14 KST. 별도 패키지 com.ullim.watch.nativeprobe,최종 APK SHA256 `e467b03933b7ffa897dd67bd5c2ecd3c9e48afa420e2ac0ff4bfa81814962bac`; 실제 설치 해시 일치. PID3218의05:32:07~05:42:38 실행을 끝까지 관측했다. [메타데이터 로그](issue22-watch7-worker-native.txt).

워치에서 생성한20ms PCM을 실제 시각에 맞춰 AudioFanOut→DSP→baseline/hybrid에 전달하고,별도 단일 실행 레인의 실제 AiWorker/AiCaptureFeed가 YAMNet을 실행했다. 합성 입력은20초 잡음/20초 변조 배음/20초3회 노크 형태를 반복한다. 난수 스트림은 계속 이어지므로 OFF/ON 전체 PCM이 bit-identical하지는 않다. 각 프레임의 baseline/hybrid 비교는 정확히 같은 DSP 특징을 공유한다.

실제 마이크·진동 모터·원음 파일·네트워크/폰 호출은 없다. ADB WiFi와 충전은 유지했다(plugged=4). 기기를 물리적으로 인터넷/폰과 분리했다고 주장하지 않는다. 주변 온도는 측정하지 않았다.

처리 시각은 AudioFrame 복사/fan-out/DSP/매핑/worker.offer를 포함하며,합성 샘플 생성은 실제 전달 간격/지각에 포함한다. 분당 메모리 계측도 같은 생산자에서 실행하므로 측정값에는 계측 부담이 있다. 모든 간격이20ms 이하였다고 주장하지 않는다. OFF가 먼저 실행돼 JIT/초기화 차이도 있으므로 ON의 더 낮은 처리 P95나 비슷한 CPU합계를 AI 비용 없음/가속 증거로 해석하지 않는다. 프로세스 CPU는 여러 스레드의 합이며 워치 전체 사용률이 아니다. 물리적 소리→모터 지연을 측정한 값도 아니다.

## 종료·남은 범위

최종 PASS와 모델 닫기를 관측한 뒤 시험 패키지만 제거했다. 그 시점 기존 울림 APK6a2e6e16…3006c/보정값47a0c314…f06c의 SHA256,마이크 미실행,사용자 화면 유지 값1을 확인했다. 이후 실제 앱의 별도 AI 수정 설치는 PR73 기록을 따른다.

#21의 실제 ON/OFF 촉감,현재 전체 앱의 마이크/포그라운드 서비스·사용자 토글·화면 꺼짐·실패/권한 회수 통합은 아직 검증하지 않았다. 현재 전체 앱의 추가 UI 메타데이터를 포함한 AiWorker와 원본0278 실행기를 동일 소스로 혼동하지 않는다. PR60/#22는 이 결과만으로 머지/종료하지 않는다. #17/#18/#37의 실제 강약·연속성·지연과 최종 AI 유용성도 남는다.

재현: `./gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug -PnativeCaptureProbe=true -PnativeProbePackage=true`; 별도 패키지 설치 후 NativeClassificationProbeActivity를 `com.ullim.watch.PROBE_AI_WORKER` action으로 실행하고 약10분30초의 최종 결과를 기다린다. 다른 앱으로 전환하면 취소되며,중단/오류/열 가드가 발생하면 완료로 기록하지 않는다.
