# 최종 사용자 설정을 앱 기본값으로 고정 — 2026-11-14

사용자가 조정을 마친 워치의 실제 DataStore를 원음 없이 읽었다.35개 수치와 민감도125%/AI ON을 `MvpDefaults`에 고정했다. 신규 설치, 누락·손상 설정 복구, 전체/상세/항목별 기본값 복원과 화면의 기본값 표시에 같은 프리셋을 사용한다. 유효하게 저장된 기존 선택은 우선하며 기존 모터 프로필은 변경하지 않는다.

사용자 최종 선택의 주요 값: 강한 입력 기준50%, 작은 소리 곡선1.5, 최소 입력0.6%, 시작 추가 기준1.5%/유지0.5%, 강약 대비1,25%지점 진동10%/50%지점42.349127%/80%지점100%, 최소/최대 출력4%/100%, 긴 펄스60~75%, 묶음60ms, 최소ON3ms, 유사도2ms, 무음 연결20ms, 모터 제거1.5/잔향200ms. 전체 캡처값은 [37개 원본 설정 스냅샷](../../app/src/test/resources/final-mvp-settings.properties)에 있다.

이는 사용자가 선택한 프리셋 고정 작업이다. 발소리 감쇠 기능, AI분류/보정 정책, 신호처리·렌더링 알고리즘, 원음 저장은 추가하지 않았다. 신호처리기의 내부 기준인 `TuningSettings.DEFAULT`는 유지하고 앱의 기본값만 별도 프리셋으로 지정한다.
