# 실제 추론 시간 초과의 제한 복구

2026-11-14, PR77 설치본의 사용자 착용 피드백 후 원음 없는 Watch7 로그를 확인했다.

- session1에서 실제 YAMNet이 LISTENING, 모델 로드, 최대 관측 추론 약101ms, attempts/validResults 294회까지 확인됐다. 이는 분류 정확도나 촉각 정책 적용률을 뜻하지 않는다.
- 이후 session2에서 AI_INFERENCE_TIMEOUT/FAILED, attempts=0/validResults=0이 확인됐다. 이전 세션의 실패가 재시작에도 유지된 상태에서 DSP-only 폴백으로 실행된 기록이다. 첫 발소리를 AI가 학습해 이후 발소리를 지웠다는 근거는 없다.
- 마지막 관측 구간의 진동 명령 최댓값은 약43~65%, 입력 RMS는 보정 전후 차이가 있었고 일부 보정 후 RMS는0이었다. 소리 종류/발생 시점을 표시한 시험이 아니므로 사라진 외부 발소리를 특정하는 근거로 쓰지 않는다.
- 메인의 입력 소리 %는 보정된 디지털 RMS×100, 진동 명령 %는 매퍼의 요청값×100이다. 실제 음압·모터 가속도의 백분율이 아니다. 기존 출력 상한은85%이며 이번 변경은 세기 곡선을 바꾸지 않는다.

## 변경

AiWorker는 일시적 추론 시간 초과 후 5초 이상 지나고 기존 native 추론과 모델 정리가 끝났을 때 세션당 한 번 자동 재시도한다. DSP는 계속 동작한다. OFF/중지 시 재시도하지 않고, 두 번째 시간 초과나 모델 로드/정리/실행 오류는 실패로 표시한다. 같은 worker/lane을 재사용하며 실행 중인 native 호출과 close를 겹치지 않는다.

디버그 수치에 AI가 실제 진동값을 바꾼 프레임 수, 모터 보정 프레임 수, 보정 후 무음이 된 프레임 수, 약/중/강 명령 구간 수를 추가했다. 원음·발화 내용·분류 레이블은 기록하지 않는다. 보정 후 무음은 모터 자체의 소리가 제거된 경우도 포함하므로 외부음 누락 증거로 단정하지 않는다.
