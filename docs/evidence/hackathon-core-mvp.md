# 해커톤 핵심 촉각·AI 개선 (2026-11-14)

기준 main `9e111fa`, 브랜치 `fix/hackathon-core-haptics-ai`. 사용자 승인 범위에 따라 현재 펄스 출력 주기와 모터 프로필 형식을 유지하고 아래 변경을 통합했다.

- NoiseGate는 활성 소리를 배경으로 흡수하지 않는다. 현재 RMS로 소리 종료를 확인하고, 종료 뒤 엔벌로프 잔향 대신 현재 RMS로 배경 기준을 갱신한다. 모터 보정 구간에는 기준 학습을 멈춘다. 일정한 실제 외부음은 계속 전달하는 정책이며 과거 #9의 일정 소음 자동 소거와는 의도적으로 다르다.
- 생산 AudioFanOut에서 모터 보정을 20ms당 한 번 수행하고 같은 보정 PCM을 DSP와 AI에 전달한다. 보정용 생성 PCM의 시간/세션/길이를 유지한다. AI 첫 창은 완성된 20ms 프레임까지 기다릴 수 있지만 DSP는 추론을 기다리지 않는다.
- AI는 작은 배율 대신 detail/contrast 단조 곡선을 사용한다. 짧은 사건 중간에 늦은 AI로 곡선을 바꾸지 않고, 500ms 이상 지속된 사건에는 늦은 첫 정책을 점진 적용한다. 무음·시간축·OFF 복귀는 보존한다. 종류별 고정 알림 패턴은 만들지 않는다.
- 신규 AI 기본값 ON, 저장된 OFF는 보존한다. 화면 문구와 설정/모델 문서를 맞췄다. AI ON만으로 마이크나 모델을 시작하지 않는다.
