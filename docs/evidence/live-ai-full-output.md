## 사용자 요청에 따른 변경

- 85% 상한을 baseline/AI 곡선/PulseFallback/표준 amplitude/envelope 출력에서 제거했다. full pulse는20ms 중20ms ON, 표준 amplitude는255를 요청할 수 있다. 실제 모터 가속도100%를 측정했다는 뜻은 아니다.
- baseline의 입력 level0..0.5를 출력0..0.8에, level0.5..1을 출력0.8..1에 배정했다. 단조성을 유지하면서 중간 입력에도 더 큰 요청을 만들고 상단에서는 완만하게 변화한다. AI 곡선 역시0..1을 사용한다.
- 고출력 보정 단계를100% 출력으로 변경했다. 장치 키에 output=100을 포함해 기존85% 범위의 보정과 구분한다. 파일 형식을 바꾸거나 기존 수치를 삭제하지 않으며 시작 전 새3초 보정이 필요하다. 워치 기존 숫자 프로필4262bytes와 직전 APK를 로컬 artifacts에 백업했다.
- 메인에 AI 상태와 분석 진입을 그래프보다 먼저 표시한다. 분석 화면에는 신선한 YAMNet 원시 후보3개·모델 점수, 안정화된 확정 결과, 추론/자동 복구 횟수, 실제 AI 촉각 정책을 표시한다. 원시 후보가 불확실해도 후보로 볼 수 있지만 확정 인식이나 정책 적용으로 표시하지 않는다.
- 마이크 원입력→모터 보정 후 입력, 기본 진동→AI 후 요청을 표시한다. 순간 상대값이며 입력 %와 출력 %는 서로 다른 기준이다. 종류별 소리 분리·제거와 모터 소음 보정을 구분해 설명한다. 원음과 후보 레이블을 로그에 저장하지 않는다.
