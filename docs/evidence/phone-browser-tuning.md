## 사용

1. 워치 메인에서 직접 소리 감지를 시작한다.
2. 메인 또는 설정/상세 조절에서 **휴대폰에서 조절**을 누른다.
3. 같은 핫스팟의 휴대폰 브라우저에 워치에 표시된 `http://IP:포트/세션경로/`를 입력한다. 마지막 `/`까지 포함한다.
4. 강약 곡선의 세 점을 드래그하거나 자주 쓰는 슬라이더/숫자를 바꾼다. 모든35개 값은 상세 설정 아래에 유지한다. 실제 감지 상태·입력/보정/변환/진동 요청을 함께 본다.
5. **워치에 저장됨**을 확인한다. 현재 값 JSON 내려받기도 제공한다. 조절이 끝나면 워치의 **연결 닫기**로 통로를 닫아도 저장한 설정과 감지는 유지된다.

조절 동안 워치 연결 화면을 열어둔다. 해당 화면이 중지되면 로컬 통로를 닫고 임시 주소 파일을 지운다. 다시 열면 세션 경로가 달라진다. 휴대폰과의 블루투스 연결만으로 웹 조절이 되는 것은 아니며 동일한 로컬 Wi-Fi 연결이 필요하다. 이 화면은 마이크를 자동 시작하지 않고 수치 설정/상태만 주고받는다. 원음은 제공하지 않는다.
