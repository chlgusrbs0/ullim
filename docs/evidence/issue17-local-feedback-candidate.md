## 수정

- 명시적인 약3초 보정: 실제 live와 같은60ms 재요청 두 묶음에서 조용한 입력과 모터 전력 스펙트럼의 수치 경계를 얻는다. 원본 PCM·위상·음성은 저장하지 않는다. 조용한 기준/안정 구간의 표본 수가 모자라거나 출력이 무시되어 모터 성분을 검출하지 못하면 실패하며 기존 보정값을 덮어쓰지 않는다.
- 512-point FFT 전력 경계로 모터 성분을 빼고 역변환한 **DSP 분기만** 분석한다. AI 분기는 기존 메모리 fan-out 그대로다. 실제 성공한 요청의 과거 시각과120ms 이내 tail에 겹치는 오디오만 보정한다. 지연 도착 오디오를 최신 요청 시각과 혼동하지 않으며 이력은256구간으로 제한한다.
- 모델은 private noBackupFilesDir에 숫자로 atomic 저장한다. 모델/펌웨어/읽을 수 있는 시스템 진동 설정 키가 달라지거나 파일이 손상되면 다시 보정한다. 착용 조건 변화는 자동으로 판별하지 못하므로 같은 착용 상태에서 보정하도록 안내한다.
- 보정값이 없거나 손상되면 메인과 서비스 모두 마이크 감지 시작을 막고 진동 진단의 명시적 보정으로 안내한다. 기존의 알려진 반복 진동 경로로 조용히 돌아가지 않는다.
- 이미 amplitude1/255 실패가 실기기에서 확인된 **SM-L300의 ZZI1/ZZK1에 한해서**, 20ms 명령 구간의 켜짐·꺼짐 비율을 세기에 따라 달리한다. 예를 들어 요청.2는4ms 켜짐, 요청.8은16ms 켜짐이고 구간 전체20ms는 그대로다. 다른 모델/미검증 펌웨어에 이 정책을 일반화하지 않는다. 보정도 선택한 실제 출력 방식을 사용한다. 이는 표준 연속 amplitude 제어가 고쳐졌다는 뜻이 아니며 강약 체감·연속성은 실제 워치에서 평가해야 한다.
- 화면 이탈·중지는 보정 타이머/출력을 취소하고 실제 release 완료까지 기존 단일 마이크 lease를 유지한다. timer 취소와 native terminal callback은 다른 Handler로 분리해 종료 신호를 지우지 않는다. 보정 뒤 자동 감지를 시작하지 않는다.
