# Final MVP defaults

사용자가 조정을 종료한 워치 DataStore35개와 민감도/AI선택을 그대로 신규 설치 기본값으로 고정한다. 새 발소리 감쇠와 알고리즘 변경은 범위에 포함하지 않는다.

- [x] 워치의 실제 저장값을 읽고 손실 없는 숫자 스냅샷을 백업한다.
- [x] MvpDefaults에37개 값을 정의하고 최초 시작/누락 설정/기본값 복원/화면 기본값 표시에 연결한다. 기존 저장값은 우선한다. 신호 처리기의 기존 기준값은 보존한다.
- [x] 캡처한 값과 새 기본값의 Float비트 일치, 기존 저장값 보존, 부분/손상 설정 복구, 보정20%/100% 파형 일치를 검사한다. 기존 설정 UI검사는 최종 민감도125%를 반영한다.
- [x] 기존289개 검사와 신규4개 기본값 검사 통과. 비교 파일 경로만 수정해 해당4개를 다시 확인했다. APK/Lint성공. PR/설치 결과는 증거 문서와 PR에 기록한다. 실기기 보정값과 사용자 저장값을 지우거나 감지를 자동 시작하지 않는다.
