# Live detailed tuning implementation plan

사용자는 프리셋 대신 강약 계산의 값을 각각 직접 조절하는 화면을 요청했다. 해커톤 우선 지침에 따라 추가 승인·코드별 반복 검사 없이 하나의 변경 묶음으로 구현한다.

- [x] 입력/무음·크기 정규화, 반응/감쇠/짧은공백, 진동 곡선/세 지점, 펄스 전환/묶음, 모터 보정, AI의35개 수치를 불변 설정으로 정의한다. 현재 동작을 기본값으로 유지하고 관계 있는 경계는 유효한 순서를 지킨다.
- [x] 기존 DataStore/SettingsController를 확장해 조절 즉시 메모리에 반영하고 자동 저장한다. 기존 민감도·AI 선택을 보존한다.
- [x] 각 처리 단계가 프레임별 설정을 읽게 한다. 원음·종류별 고정 세기·샘플링/60ms 전송 일정은 바꾸지 않는다. 짧은공백 유지 기본0이며 선택했을 때만 최대100ms로 제한한다.
- [x] 설정 및 메인에서 열 수 있는 전용 조절 화면을 만든다. 그룹→항목→수치 직접입력/+/−, 현재 입력/감지 유무/요청, 중지, 항목/전체 기본값 복원을 제공한다. 설정만 열어서 마이크를 시작하지 않는다.
- [x] 보정의20%/100% 파형이 모든 허용 펄스 설정에서 같게 범위를 잡아 매번 재보정을 요구하지 않는다. 타이밍이20ms 프레임·60ms 전송 일정임을 조절 안내에 표시한다.
- [x] 저장/실시간 반영/순서 경계/기본값 동일/공백 유지 상한 및 조절 화면을 포함해 테스트·APK·Lint를 한 묶음 실행한다. 첫287개 중 화면 준비2건 시간 초과 후 저장 완료 대기를 보완하고 영향 범위30개·빌드·Lint를 확인했다. PR/설치 결과는 증거 문서와 PR에 기록한다. 사용자 소리 수집은 자동 시작하지 않는다.
