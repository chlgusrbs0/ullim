# 프로젝트 현황

[문서 안내](README.md)

울림은 2026년 11월 14일 해커톤 MVP로 구현한 Watch7 앱이다. 최종 런타임은 기존 상태 그대로 보존한다. 35개 상세 수치, 민감도 125%, AI 켜짐을 기본값으로 적용하고 설치했으며 기존 설정과 모터 보정 파일 보존을 확인했다.

2026년 11월 28일 프로젝트 정리에 따라 이전에 열려 있던 추가 검증·보류 이슈 21개를 **진행 계획 없음(Not planned)**으로 종료했다. 이는 구현되지 않은 항목의 완료, 평가 합격 또는 정식 v1.0 인수를 뜻하지 않는다. 필요할 때 기존 이슈를 다시 열 수 있다. 이번 문서 정리에서 앱 코드·빌드·실기기 시험을 변경하거나 새로 실행하지 않았다.

## 구현과 확인 범위

| 영역 | 최종 MVP에서 구현된 내용 |
| --- | --- |
| 오디오·DSP | 명시적 시작·중지, 마이크 포그라운드 서비스, 노이즈 바닥·크기 변환 및 무음 처리 |
| 촉각 출력 | Watch7의 엔벌로프 미지원에 대응한 표준 Waveform·펄스 폴백, 60ms 유한 배치 및 중지 장벽 |
| 모터 간섭 | 조용한 착용 상태에서 보정 및 자기 진동 재입력 억제 |
| AI | 비동기 YAMNet 추론, 같은 문맥에서 제한된 미세 보정, 기본 DSP 유지, 제한적 시간 초과 복구 |
| 세션·오류 | 중복 세션 차단, 정리 장벽, 원인별 오류와 수동 복구 |
| 화면·설정 | 실제 상태 기반 시작·중지, 입력·진동 명령 그래프, AI 후보·점수·불확실 상태, 35개 상세 설정 저장과 선택적 브라우저 조절 |
| 권한·접근성 | 최초 안내와 동의, 권한 허용만으로 마이크를 시작하지 않음, 큰 글씨·스크린리더 의미와 터치 영역 대응 |

실제 Watch7 설치·실행·감지·진동·AI 실행과 설정 저장의 기존 기록이 있다. 앱이 명령을 보낸 사실과 사용자가 실제 진동 차이를 구별한다는 사실은 다르다. [최종 기본값 기록](evidence/final-mvp-defaults.md)과 [실험 자료 안내](evidence/README.md)를 참고한다.

## 미완료 평가와 보류

| 평가 영역 | 남은 확인 |
| --- | --- |
| 마이크·서비스 | 전체 화면 꺼짐·잠금·통화 경쟁·권한 회수·강제 종료·재시작 시나리오 |
| 진동 | 최신 출력의 물리 종료, 잔여 진동, 반복 품질, 자원 평가 |
| 모터 간섭 | 외부음 중첩 보존과 물리 지연의 통제 평가 |
| AI | 동일 조건 켜짐/꺼짐 비교, 전체 앱 성능·발열·자원 사용과 원인별 평가 |
| 세션·오류 | 빠른 반복·강제 종료·실패 회복 전수 검증 |
| 화면 | 동적 그래프·화면 꺼짐·긴 분류명·대표 AI 상태 전수 확인 |
| 권한·접근성 | 최초 허용·거절·영구 거절, 실제 TalkBack과 원형 화면 접근성 |
| 추가 정비 | 백업·이전·개인정보 전수 감사, 전체 외부 네이티브 구성요소 출처·고지 감사, 추가 UI 다듬기 |

물리 반응 지연 P95, 강도·리듬 블라인드 구별률, 통제 AI 효과 및 대상 사용자 효과는 정식 평가되지 않았다. 기존 블라인드 강도 3단계·리듬 3종 각각 80% 이상, 물리적 반응 P95 500ms 이내의 목표는 달성 결과가 아니라 원래 평가 기준이다. 전체 실기기 인수와 알려진 차단 결함 0건의 확인도 완료되지 않았다.

## 결과물과 유지보수

최종 Debug APK 및 설정 스냅샷은 당시 작업공간의 별도 산출물이며 공개 배포하지 않는다. 재현은 개발 및 설치 안내에 따른다. [해커톤 시연 인계](demo-package.md)는 당시 대본과 파일 정보이지 전체 시연 성공의 증명이 아니다.

과거 85% 출력 상한의 Waveform 초안은 후속 구현으로 대체됐다. 추가 백업·개인정보 감사, 전체 외부 출처 고지 감사, 추가 아이콘·큰 글씨 개선 초안은 미병합 종료 상태다. 이전 PR 및 이슈의 실패·미측정·보류 기록은 GitHub 이력과 실험 원본에 보존한다.

저장소는 아카이브하지 않으며 새 기능이나 평가를 자동으로 진행하지 않는다. 향후 유지보수 시 실제 필요에 따라 재개한다.
