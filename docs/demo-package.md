## 30~60초 시연 순서

1. **소개:** 청각 정보를 지속적으로 확인하기 어려운 상황에서 소리의 강약·지속·리듬을 손목으로 느끼는 Watch7 단독 프로토타입이라고 설명한다. 평소 사용은 화면을 계속 볼 필요가 없다.
2. **시작:** 워치를 착용하고 울림의 ‘소리 감지 시작’을 누른다. 이미 유효한 보정이 저장되어 있으면 다시 보정하지 않는다.
3. **촉각 설명:** 작은/큰 목소리와 짧은/이어지는 소리를 비교한다. 같은 거리에서 소리를 내고 강약·길이 변화가 진동 요청에 반영된다는 점을 설명한다. 강약을 딱3단계로 분류하는 기능이라고 설명하지 않는다.
4. **AI 설명:** 필요하면 ‘AI 분석 보기’에서 후보·점수·적용 상태를 보여준다. AI는 소리 종류를 분류하고 확실한 연속 문맥의 작은 진동 흔들림을 보정한다. 첫 반응과 큰 변화는 별도 소리 경로가 즉시 처리한다.
5. **중지:** 앱 또는 작동 알림의 ‘중지’를 누른다. 노트북·휴대폰은 필요하면 설정을 크게 보여주는 선택 도구라고 설명한다.

이 문서는 시연 대본이며 위 절차를 새로 실행하거나 새 실험 결과를 추가한 기록이 아니다.

## 현장에서 확인할 지점

| 상황 | 확인/대응 |
|---|---|
| 진동이 없음 | 먼저 앱이 ‘소리 감지 중’인지 확인한다. 권한·보정 안내가 있다면 해당 안내를 따른다. |
| 보정이 필요하다는 안내 | 손목에 착용하고 조용히 ‘모터 간섭 보정 ·3초’를 진행한다. |
| AI가 준비/지연/오류 상태 | 기본 소리→진동 경로는 유지된다. AI 상태를 정상 인식처럼 설명하지 않는다. |
| 브라우저 조절 연결 끊김 | 선택적 설정 통로의 문제다. 워치 단독 감지와 구분한다. 필요한 경우 워치의 연결 화면을 다시 열어 현재 주소를 사용한다. |
| 처음 설치하는 워치 | 마이크 권한·최초 안내·기기별 모터 보정이 필요할 수 있다. 다른 손목의 보정 파일을 복사하지 않는다. |

## 발표에서 사용할 수 있는 표현

- 실제 소리 크기·길이·리듬을 따라 진동 요청이 달라진다.
- 번들 YAMNet이 워치에서 실행되고 분류 문맥으로 작은 출력 흔들림을 보정한다. 최종 기본값의 보정 한계는±3%포인트다.
- 원음 파일을 저장·전송하지 않고 워치에서 처리한다.
- 본인 발소리만 제거하거나 음원을 분리하는 기능, 물리 지연/블라인드 구별률 합격, AI의 통계적 개선 효과는 주장하지 않는다.
